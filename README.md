# DialSyria — ديل سيريا

نشرة أخبار يومية بالاشتراك: أخبار سوريا والعالم تُجمع وتُصنّف تلقائياً، وتصل إلى بريد المشترك كل يوم في الساعة التي يختارها. عربية أولاً مع دعم كامل للإنجليزية، تصميم موبايل أولاً بروح "الصحيفة الرقمية".

**الموقع الحي:** https://dial-syria.pages.dev — **لوحة الإدارة:** https://dial-syria.pages.dev/admin

## البنية (كلها ضمن الخطة المجانية على Cloudflare)

- **Frontend**: React 19 + Vite (SPA، RTL/LTR، خطوط Amiri + Cairo مستضافة ذاتياً)
- **Backend**: Cloudflare Pages Functions (`functions/api/*`)
- **قاعدة البيانات**: Cloudflare D1 — `dialsyria-db`
- **مصادر الأخبار**: RSS (Google News استعلامات لكل موضوع + BBC عربي + عنب بلدي) → تصنيف بالكلمات المفتاحية → إزالة التكرار → تخزين
- **الإرسال**: Brevo API (مجاني 300 بريد/يوم) — نشرة HTML بتصميم تحريري لكل مشترك حسب لغته
- **المجدول**: Worker منفصل `dialsyria-cron` — تجميع كل 20 دقيقة، إرسال النشرات عند الساعة :07 لكل ساعة (توقيت دمشق)
- **الدخول**: رابط سحري بالبريد بدون كلمات مرور · **الإدارة**: كلمة مرور في متغيرات البيئة

## متغيرات البيئة (Pages → Settings → Variables)

| المتغير | الوظيفة | ملاحظات |
|---|---|---|
| `ADMIN_PASSWORD` | دخول لوحة الإدارة | مضبوط بالفعل — القيمة في `.dev.vars` المحلي |
| `CRON_SECRET` | حماية `/api/ingest` و`/api/digest` | مضبوط بالفعل |
| `BREVO_API_KEY` | إرسال النشرات | **أضفه عندك** (انظر أدناه) |
| `SENDER_EMAIL` | بريد المُرسِل | بريد موثّق في Brevo |

## تفعيل البريد (خطوتان، مجاني)

1. حساب مجاني على [Brevo](https://www.brevo.com) → SMTP & API → إنشاء مفتاح API
2. في Brevo: Senders → إضافة بريدك والنقر على رابط التوثيق الذي يصلك
3. في Cloudflare Pages → dial-syria → Variables:
   - `BREVO_API_KEY` = المفتاح
   - `SENDER_EMAIL` = بريدك الموثّق

قبل إضافة المفتاح: روابط الإدارة تظهر مباشرة في الواجهة (وضع التطوير). بعدها تصلك بالبريد فقط.

## الأوامر

```bash
npm install          # تثبيت
npm run dev          # تطوير محلي
npm run build        # فحص الأنواع + بناء
npm run deploy       # بناء + نشر إلى Pages
npm run db:schema    # تطبيق مخطط D1 (مرة واحدة)
```

## واجهات API

| المسار | الطريقة | الوظيفة |
|---|---|---|
| `/api/subscribe` | POST | تسجيل/تحديث اشتراك (تجربة 3 أيام تلقائية) |
| `/api/login` | POST | إرسال رابط دخول سحري |
| `/api/me?token=` | GET/PATCH/DELETE | عرض/تعديل/إلغاء الاشتراك |
| `/api/news` | GET | أخبار آخر 24 ساعة (عامة) |
| `/api/ingest` | POST | تجميع الأخبار (x-cron-secret) |
| `/api/digest` | POST | بناء وإرسال نشرات الساعة الحالية (x-cron-secret) |
| `/api/admin/login` | POST | دخول الإدارة |
| `/api/admin/subscribers` | GET/POST | قائمة المشتركين + الإحصاءات / تنفيذ إجراء |

## التوسع للمستوى الوطني — الخيارات

- **البريد**: Brevo (300/يوم مجاني) → Mailgun/SendGrid عند آلاف المشتركين
- **الواتساب**: WhatsApp Business API (~0.05$/محادثة، يتطلب توثيق Meta Business) — الواجهة جاهزة لعرضه "قريباً"
- **الدفع**: تفعيل يدوي الآن → USDT أو حوالات لاحقاً؛ Stripe غير متاح في سوريا
- **المصادر**: إضافة مصادر RSS سورية مباشرة، أو NewsAPI/GDELT عند الحاجة
- **النطاق**: dial-syria.pages.dev مجاني الآن → نطاق مخصص (~10$/سنة) يُربط من Dashboard → Custom domains
